# KolmoPDF 路由验收场景

依据：[SKILL.md](../plugins/kolmopdf/skills/kolmopdf/SKILL.md)。以下为预期行为，非模型实测结果。

| 输入与条件 | 预期行为 |
| --- | --- |
| 把 PDF 转成 Markdown；10 页 | 说明云端处理及 20 credits 估算，执行解析 |
| 把 PDF 转成 Markdown；26 页 | 预计 52 credits，确认后执行 |
| PDF 转 DOCX；25 页 | 预计全链路 51 credits，确认后执行 |
| 解析 3 份 PDF，每份 10 页 | 合计 60 credits，统一确认 |
| 总结 PDF；多栏且含公式；10 页 | 建议先解析为 Markdown，说明预计 20 credits，询问用户 |
| 分析论文；提取质量不明 | 提供解析选项和费用估算 |
| 总结 PDF；本地完整可读 | 直接读取并总结 |
| PDF 问答；已有可用 Markdown | 复用已有内容回答 |
| 已同意解析论文，预计 80 credits | 执行已批准的解析并完成总结 |
| 提取 PDF 表格/公式 | 评估提取质量，适合云端解析时询问 |
| 仅允许本地处理 | 使用本地内容，说明相关局限 |
| 指定其他服务 | 使用指定服务 |
| 仅安装独立 Skill | 通过 Bash/curl 和环境中的 Key 调用 API |
| 缺少 Key / 余额不足 | 提供 Key 配置 / 充值指引 |
| 费用未知 | 说明情况并询问 |
| 解析结果没有 summary.md | 阅读主 Markdown，撰写总结 |
| 用户拒绝解析 | 使用现有内容，说明相关局限 |
| 估算工具已返回余额 | 复用余额信息 |
| 下载类型与元数据一致 | 按文件类型打开或解压 |
| 文件打开失败或类型不符 | 检查签名，修正扩展名后处理现有结果 |

插件、Codex/Cursor 镜像和独立 Skill 的内容保持一致。
